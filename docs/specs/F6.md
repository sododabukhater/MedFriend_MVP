# F6-lite — Add medication (approved 20 Nov; built 20 Nov, not yet committed)

## Decisions (owner approved all four suggested defaults on 20 Nov)
- A. **Step-by-step: 4 short screens** vs one long form.
- B. **Delete button with confirmation on each card now** (~20 min); editing later (delete and re-add for the alpha).
- C. **"As needed" medicines left out of the alpha** (no schedule, no adherence).
- D. **Agent drafts ~50 medicine names, whole list marked REVIEW-AR for the owner/pharmacist to check**, or the owner supplies a list.

## User flow
Home → "Add medication" → 4 steps, one question per screen, progress "Step 2 of 4",
buttons Back / Cancel / Next (Next disabled until answered) → review screen → "Save medication"
→ home shows a "Medication saved" message and the new card (name, strength, amount, times).

| Step | Question | Input |
|---|---|---|
| 1 | What is the medicine's name? | Text box with up to 6 suggestions from the local list (search English or Arabic; Arabic letter variants أ/إ/ا, ة/ه, ى/ي treated as equal). Free text allowed. Optional "Strength (optional)", e.g. 500 mg. |
| 2 | What form is it? | Big buttons: Tablet, Capsule, Syrup, Injection, Inhaler, Drops, Cream/ointment, Other |
| 3 | How much do you take each time? | − / + number; unit follows the form (tablet, capsule, ml, unit, puff, drop, application…) |
| 4 | How many times a day? | 1 / 2 / 3 / 4 times; suggested times editable with the native time picker |

Suggested times: 1× 08:00 · 2× 08:00, 20:00 · 3× 08:00, 14:00, 20:00 · 4× 08:00, 13:00, 18:00, 22:00
(one per time-of-day group for F2: morning / noon / evening / night).

No medical advice: strength is never auto-filled; the app suggests clock times only, never doses.

## Medicine list
~50 entries: brand (Latin), Arabic spelling, generic name. Chronic-care classes: diabetes, blood pressure,
cholesterol, heart/anticoagulants, thyroid, stomach, asthma, pain. No Jordanian source (e.g. JFDA register)
was available to verify; the whole file is marked REVIEW-AR, and uncertain local generic brands are left out.

## Data
Supabase table `medications` (see `docs/specs/DB-supabase.md`; changed from localStorage on 20 Nov). Record: id, name, fromList (yes/no), strength, form, amount, timesPerDay,
times[], createdAt. Each device starts empty (the demo-data step comes later).

## Acceptance criteria
1. "Add medication" opens step 1 with a large text box.
2. Typing "glu" or "جلو" suggests Glucophage / جلوكوفاج; tapping fills the box.
3. A name not in the list (e.g. "Test medicine") can still be used.
4. Next is disabled until each step is answered.
5. Choosing Syrup changes the unit in step 3 to ml.
6. Choosing 3 times shows 08:00, 14:00, 20:00, each editable.
7. Saving returns home with the confirmation message and the new card.
8. After a page refresh the medicine is still there.
9. Three added medicines all show.
10. Cancel at any step returns home without saving.
12. Delete asks for confirmation; "Keep it" keeps the card, "Yes, delete" removes it (also after refresh).
13. The amount starts at 0 (the app never suggests a dose); saving offline shows a clear message.
11. Type-check and build pass; works in both languages; text ≥ 18px; buttons ≥ 48px.

## REVIEW-AR
- `src/data/drugs.ts`: whole list.
- Arabic unit words use one form for every number (e.g. "2 حبة"): keys `unit.*` in `ar.json`.
- Form names (`form.*`), e.g. حبوب for Tablet, دهنة for one application of cream.

Tests: `tests/F6.spec.ts`.

## Change 20 Nov (owner): strength is a number + a unit
Free text let anything in ("abc", "500mg", "half"). Now: a number box (decimal keypad; Arabic digits and "٫" accepted, other characters dropped, max 99999, 2 decimals) + one unit button: mg, mcg, g, ml, units, %. Both or neither (still optional); Next stays off with a short reason if only one is given. Stored as `strength_value` numeric + `strength_unit` (fixed list); the database also refuses anything else. Two-ingredient medicines (e.g. Janumet 50/1000) leave strength empty for the alpha. No strength suggestions (would look like dose advice).

14. Strength accepts only a clean number + a unit from the list (both or neither); shows in the chosen language (500 mg / 500 ملغ).
